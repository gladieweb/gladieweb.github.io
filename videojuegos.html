Integraciones y prototipos con un primer alcance concreto. Abrí una propuesta para ver un ejemplo y qué validaríamos primero.

Piloto a desarrollarAI Coding Agents para UnityVer ejemplo +

Ejemplo de primer alcance

Un agente que prepare un script C# sencillo o una herramienta de editor y proponga una prueba, usando las convenciones del proyecto.

Primer entregable
Una tarea pequeña, cambios revisables y una prueba ejecutada; la aprobación del código queda en manos del equipo.
Qué validamos primero
Compatibilidad con la versión de Unity y conexión del agente mediante las herramientas admitidas para ese proyecto.
Piloto a desarrollarMCP & tool calling en UnityVer ejemplo +

Ejemplo de primer alcance

Consultar una escena o la consola desde el asistente y ejecutar una herramienta de editor con parámetros definidos.

Primer entregable
Una integración mínima con una consulta y una operación revisable, usando CLI o MCP según corresponda a la versión.
Qué validamos primero
Acceso admitido al editor, permisos y límites de ejecución. Tengo experiencia en MCP con Grafika; aplicarlo a Unity sería un nuevo piloto.
Piloto a desarrollarAI Automated QA en UnityVer ejemplo +

Ejemplo de primer alcance

Recorrer un menú o cargar una escena de prueba, ejecutar comprobaciones y reunir errores de consola en un reporte.

Primer entregable
Un smoke test con condiciones de éxito y fallo explícitas, repetible sobre una escena acordada.
Qué validamos primero
Estabilidad del recorrido y utilidad del reporte; no se promete encontrar todos los errores ni sustituir al equipo de QA.

Los pilotos son propuestas para desarrollar, no proyectos ya entregados. Empezamos por una prueba de viabilidad con alcance y criterios acordados; la integración completa se define a partir de ese resultado.

Piloto a desarrollarAgentic Gameplay / Unreal & NVIDIA ACEVer ejemplo +

Ejemplo de primer alcance

Un NPC de prueba que interprete una petición y elija entre tres acciones autorizadas: dar una pista, señalar un lugar o iniciar un diálogo.

Primer entregable
Primero, validar la integración de un componente de ACE en una escena. Después, conectar una interacción acotada con el gameplay.
Qué validamos primero
Modelo, componentes de ACE, hardware, latencia y control de acciones. ACE y Agentic Gameplay son áreas nuevas en mi práctica.

Piloto a desarrollarMCP & tool calling en UnrealVer ejemplo +

Ejemplo de primer alcance

Dar a un asistente acceso a una consulta del proyecto o a una acción de una herramienta propia, por ejemplo inspeccionar actores o preparar un cambio revisable.

Primer entregable
Una consulta de solo lectura y una operación acotada sobre un proyecto de prueba.

Piloto a desarrollarRAG & local inference para personajesVer ejemplo +

Ejemplo de primer alcance

Un personaje que consulte un pequeño conjunto de notas del mundo para responder preguntas; evaluar por separado si un modelo local puede resolver esa tarea.

Primer entregable
Una demo de texto con fuentes recuperadas y una prueba de rendimiento local en un equipo acordado.
Qué validamos primero
Coherencia con las fuentes, respuestas fuera de contexto y presupuesto de CPU/GPU. Son propuestas de prototipo, no funcionalidades ya implementadas.

Qué validamos primero
Determinismo de la prueba y exactitud del reporte, antes de sumar más escenarios.
