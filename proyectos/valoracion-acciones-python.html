Valoración de acciones con Python

Consulta de acciones por ticker, estimación del valor intrínseco y porcentaje de infravaloración o sobrevaloración frente al precio de mercado.

El contexto

Qué se necesitaba

Automatizar una parte del análisis de value investing mediante un componente que pueda integrarse en una web.

Mi participación

Qué desarrollé

Desarrollé un script Python que recibe un ticker, como AAPL, o una lista de tickers. Consulta información mediante APIs como Yahoo Finance, estima el valor intrínseco, obtiene el precio de mercado y muestra el porcentaje de infravaloración o sobrevaloración.

  • Entrada de uno o varios tickers de acciones.
  • Obtención de información y precios mediante APIs como Yahoo Finance.
  • Cálculo de valor intrínseco estimado y comparación porcentual con la cotización.
  • Estado: script Python implementado, pensado como componente de un microservicio. La web todavía no está desarrollada.

Con qué trabajé

Tecnologías & habilidades

  • Python
  • APIs de datos financieros
  • Yahoo Finance
  • Valoración de acciones
  • Value investing
